# Checklist de revisión visual

- [ ] Revisa a 375 px: controles táctiles, lectura, scroll y ausencia de overflow.
- [ ] Revisa a 768 px: transición de layout y navegación sin superposiciones.
- [ ] Revisa a 1024 px: distribución y espacio disponible.
- [ ] Revisa a 1440 px: ancho de contenido, jerarquía y alineación.
- [ ] Comprueba dark y light según el soporte y alcance de la pantalla; registra
      cualquier variante no disponible sin ampliar la fase.
- [ ] Recorre controles con teclado y comprueba orden, activación y salida.
- [ ] Comprueba foco visible y que no quede oculto por superficies fijas.
- [ ] Activa reduced motion y comprueba que las interacciones sigan funcionando.
- [ ] Revisa loading sin presentar datos anteriores como si fueran actuales.
- [ ] Revisa errores legibles y sus acciones accesibles.
- [ ] Guarda las capturas necesarias fuera del repositorio y sin datos sensibles.
- [ ] Registra tamaños/estados observados y límites de la revisión.
- [ ] Solicita aprobación visual humana; los checks técnicos no la sustituyen.

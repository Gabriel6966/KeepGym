# Auth artwork

These local PNGs were generated with OpenAI Image Gen for the approved KeepGym
Auth prototype, then reused in the real Next.js entry experience.

- `gym-hand.png`: warm, low-light gym photograph of a hand gripping a dumbbell.
- `dumbbell-rope.png`: transparent black hex dumbbell suspended from a fine gold
  rope, visibly tied around the grip. The rope and weight animate as one asset.

These are decorative assets. They do not represent an athlete, founder, team or
product claim. No external image host, prototype phone frame or Vite scaffold is
required by the application.

The three interface SVG icons are local exports from Radix Icons, the same icon
set used in the approved prototype. Its MIT notice is in `RADIX-LICENSE.txt`.
No icon package is added to the application.
